## Данные, которые обрабатывает Tilly

### Данные, введённые пользователем

- Личная информация, которую вы добавляете в Tilly (имена, отношения, заметки, напоминания)
- Данные шифруются в вашем браузере перед синхронизацией с Jazz Cloud
- Ключи шифрования хранятся вместе с вашими учётными данными для аутентификации, чтобы сервер Tilly мог:
  - Расшифровывать напоминания при отправке push-уведомлений
  - Обрабатывать содержимое чата и пересылать его в Google для функций Tilly Chat

### Данные аутентификации

- Метод аутентификации и информация о сеансе, хранящиеся в **Clerk**
- Ключи шифрования, хранящиеся в Clerk для обеспечения доступа с новых устройств
- Tilly не собирает личные данные в аналитических целях

### Платёжные данные

- Обработка платежей осуществляется через **Stripe**
- Tilly не хранит данные вашей платёжной карты

## Сторонние сервисы

### Clerk (Аутентификация)

- Обрабатывает аутентификацию и хранит ключи шифрования
- Политика конфиденциальности: https://clerk.com/privacy

### Stripe (Платежи)

- Обрабатывает платежи за подписку
- Политика конфиденциальности: https://stripe.com/privacy

### Jazz Cloud (Хранение данных)

- Хранит ваши зашифрованные данные об отношениях
- Получает только зашифрованный текст; расшифровка происходит на серверах Tilly с использованием ключей, предоставленных Clerk, когда это необходимо для функций сервиса

### Google Gemini (Сервисы ИИ)

- Обрабатывает содержимое чата и результаты инструментов, отправленные через серверы Tilly
- Данные отправляются только при активном использовании функций Tilly Chat
- Политика конфиденциальности: https://policies.google.com/privacy

## Правовое основание (Статья 6 GDPR)

- **Исполнение договора** (Статья 6(1)(b)): Предоставление услуг Tilly
- **Законные интересы** (Статья 6(1)(f)): Улучшение сервиса и безопасность

## Хранение данных

- Данные хранятся до удаления вашей учётной записи
- Удаление учётной записи удаляет все данные и ключи шифрования
- Резервные копии автоматически удаляются в течение 30 дней

## Ваши права (GDPR)

- **Доступ** к вашим данным в любое время с помощью бесплатного тарифа и загрузки ваших данных
- **Исправление** неточных данных путём редактирования непосредственно в Tilly
- **Удаление** вашей учётной записи и всех данных путём удаления вашей учётной записи через панель управления учётной записью. Это удалит сохранённые ключи шифрования и сделает ваши данные недоступными
- **Экспорт** ваших данных через меню настроек в любое время. Вы также можете импортировать свои данные там
- **Возражение** против обработки путём экспорта ваших данных и удаления вашей учётной записи (поскольку Tilly не может функционировать без обработки ваших данных об отношениях)
- **Отзыв согласия** в любое время путём экспорта ваших данных и удаления вашей учётной записи

## Безопасность данных

- Шифрование на стороне клиента с ключами, управляемыми через Clerk для многоустройственного доступа; серверы Tilly получают доступ к расшифрованным данным только для доставки уведомлений и функций ИИ
- Стандартные отраслевые меры безопасности
- Регулярные обновления безопасности

## Места обработки данных

- **Push-уведомления и Tilly Chat**: Обрабатываются в Германии; расшифрованные данные обрабатываются только на время этих операций
- **Зашифрованные синхронизированные данные**: Хранятся на ближайшем к вашему местоположению узле Jazz Cloud
- **Сторонние сервисы**: Могут обрабатывать данные за пределами ЕС с адекватными гарантиями

## Cookies

Tilly использует только необходимые cookies для аутентификации. Cookies для отслеживания или аналитики не используются.
